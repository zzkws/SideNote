# 早期宣传海报（存档）

这里保留早期固定回答模板的海报设计，内容不代表当前 DeepSeek 伴读的回答风格。

小红书用的 5 张图，1080 × 1440（3:4）。全部用 canvas 矢量绘制，不依赖截图，
所以任何尺寸下都清晰，改文案只要动 `poster.js`。

```bash
npm run poster
```

然后打开 http://localhost:5180，点「下载全部 5 张」，得到 5 个 PNG。

## 五张的分工

| # | 作用 | 主标题 |
|---|---|---|
| 1 | 封面 · 钩住 | 读英文论文，不用再切 ChatGPT 了 |
| 2 | 痛点 · 说中你 | 不是所有生词都一样卡人 |
| 3 | 核心 · 给证据 | 划中一个词，固定给三样 |
| 4 | 广度 · 打消疑虑 | 论文自造的词，它也答得上来 |
| 5 | 行动 · 怎么拿 | 免费 · 开源 · 三步装好 |

节奏是：钩住 → 说中你 → 给证据 → 打消"我的领域行不行" → 告诉你怎么拿。
第 2 张不讲产品只讲处境，让人对号入座；第 3 张是唯一需要停下来看懂的一张。

## 改文案

`poster.js` 里每张是一个 `posters.push(function (ctx) { ... })`。
`card()` 复刻产品的输出卡片并返回高度，用它排后面的元素，改了字号也不会撞页脚。

页脚固定在 y = 1308，内容排到 1290 以内为宜。
